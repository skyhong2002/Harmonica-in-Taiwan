## 名稱資料契約

`data/sources/source-name-translations.json` 是公開參考譯名，不代表官方名稱。以既有來源 `id` 關聯；`sourceName`、`sourceNameEn` 必須與目前快照一致才採用，避免來源身份更新後沿用錯誤譯名。

`names.original` 保留收錄名稱，不會將中文編輯名稱冒稱為官方日文／韓文原名；`namesMeta` 標示 reference。原有 `name`、`nameEn`、連結、slug 與原始貼文維持。詞彙與機構描述提供參考翻譯，沒有可靠當地譯名的人名保留可識別專名。

翻譯使用既有本機 Codex 隔離推論並逐批審閱，共用既有每小時上限；沒有訪客即時推論、付費 API fallback 或提高 Apify 預算。新來源缺譯名或名稱改變時，先回退收錄名稱；維護者審閱並更新參考譯名資料後才顯示新譯名。

## 實際資料限制

樂譜是曲目與出版線索索引，沒有假造下載、譜面或封面。驗收快照39筆出版／集合的佐證網址與現有貼文沒有精確交集，原始資料也未提供圖片，因此不能聲稱已取得真實樂譜公告海報。介面及後端已支援未來有明確佐證的原文與多媒體；fixture 僅用於隔離測試，未寫入正式資料。
