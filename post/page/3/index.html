今年迎新，我們把猜歌大賽變成一場寶可夢捕捉挑戰！
🎮 活動玩法
1. 每題播放由口琴音檔演奏的曲目，參賽者使用手機進行節奏遊戲，取得第一階段分數
2. 節奏遊戲結束後進入猜歌環節，答對曲目的隊伍可獲得加分
3. 該題總分最高的隊伍，可成功捕捉該題寶可夢
4. 全部題目結束後，依各組捕捉到的寶可夢計算點數，最高分隊伍即為第一名！
🏆 活動獎品
